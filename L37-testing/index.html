Apéritif Before we start

Questions from last time?

Dialogs, focus, shadcn/ui, colours you can read.

01

Why does every DialogContent need a DialogTitle?

The title is the dialog's accessible name. Without it a screen reader says just "dialog": which one? Today you will see the same name from the other side: a test finds the dialog with getByRole("dialog", { name: "Your order" }).

02

What does asChild do?

It renders your child element instead of its own, with the parent's classes and behaviour. A Link that looks like a button, and no <a> inside a <button>.

03

How much contrast does text need, and the focus ring?

4.5 to 1 for normal text, 3 to 1 for the visible state of a control. Our first ring was 1.66 to 1: too faint, and no test would have told us. Hold that thought.

Do: Wait for real questions first. If nobody asks, press next for the backup questions, and ask the room before you reveal each answer.

Why these three: question 1 is the bridge: the name we gave a dialog is exactly what a test looks for. Question 3 plants a seed: some things (a ring that is too faint) a test cannot see, and we will say honestly what tests are not good at.

                When the fake kitchen lies
                
  
                
    
                A fake answer with the wrong shape
                http.delete("/api/v1/learning/cart",

                The page says "No connection. Try again." api() reads JSON, and an empty body is not JSON: the error is a SyntaxError, not an ApiError. Our first version of this handler did exactly that.
                Copy the shape from the API's own page: the cart calls answer 200 with the cart
                
    
                The safety net with the old name
                server.listen({ onUnhandledRequest: "error" })
                MSW 3 ignores it: no error at run time, only a warning for the requests nobody planned. tsc notices: error TS2353: … 'onUnhandledRequest' does not exist in type …
                onUnhandledFrame: "error", and let tsc -b check the test files too
                
    
                A store nobody empties
                afterEach(() => localStorage.clear())
                expected { token: 'token-123', user: { …(3) } } to be null: green alone, red in the suite. The store is a variable in memory; the storage is only its backup.

                expect(row).toHaveTextContent("10/20/2026, 11:10:00 PM")
